# BiblioFuse NAS 0.1.10

Released 2026-08-10.

## Synology package

- The DSM 7 x86-64 package is `BiblioFuseNAS-0.1.0-0045-x86_64.spk`.
- Its SHA-256 checksum is published beside the package in this release.
- The package was validated working on physical Synology hardware.

> **Important:** Install this package only with [BiblioFuse for iOS 2.1.8 (105) or later](https://appstoreconnect.apple.com/teams/94c57d4b-571f-4fc1-bee8-61d285a65029/apps/6758330093/testflight/visionos/768998c3-02f2-45e6-b22a-30599d0485ae).

## Docker image

This package-only release does not change the Docker image. Continue to use
`ghcr.io/mlt-solutions/bibliofuse-nas:0.1.9` for Docker and Synology Container Manager.

## One host method per NAS

Do not run the Docker/Container Manager host and native Synology package on the same
NAS. Both intentionally use ports `7342` and `7343`; choose one host method per NAS.
