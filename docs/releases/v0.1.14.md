# BiblioFuse NAS 0.1.14

Released 2026-10-11.

## Browser reader resumes at the right page

- **Continuous comic and PDF reading:** reopening a book now returns to the page you
  left on. Previously the saved position could be replaced while the reader scrolled
  through the earlier pages, so the book opened at the wrong place. The reader now
  jumps straight to the saved page, stays there while images above it finish loading,
  and the footer page label follows the page you are on.
- No data format changes. Progress, bookmarks and annotations from 0.1.13 carry over.

> **Important:** Use BiblioFuse for iOS 2.1.15 or later and
> BiblioFuse for Android 2.0.16 or later on each device.


The image supports `linux/amd64` and `linux/arm64` and includes OCI provenance and SBOM
attestations. Multi-platform digest: `sha256:436904f6c95468b84aab8889a0789e3823c2812fc19ba0b4eb21b7738e0ecf6d`.

The versioned Compose files in this release's source tree ([`docker/compose.yaml`](../../docker/compose.yaml)
and [`synology/compose.yaml`](../../synology/compose.yaml)) now default to this tag. The
0.1.13 Compose files still pointed at 0.1.12, so Docker hosts that used them did not get
the sync release; pull `0.1.14` (or set `BIBLIOFUSE_IMAGE`) to receive both.

## Upgrading

Back up the config folder first (Settings can download a BiblioFuse backup). Attached
folders, catalog, reading progress and settings carry over. Docker hosts pull the new tag
and recreate the container; Synology package users update in place.

## One host method per NAS

Do not run the Docker/Container Manager host and native Synology package on the same
NAS. Both intentionally use ports `7342` and `7343`; choose one host method per NAS.
