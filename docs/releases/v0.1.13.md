# BiblioFuse NAS 0.1.13

Released 2026-10-10.

## Progress, bookmarks and annotations stay in sync across your devices

- **Reading progress:** the browser reader and your BiblioFuse apps on iPhone, iPad,
  Android phones and Android tablets now share one reading position per book. Start in
  the browser and continue on a phone or tablet at the same place, or the other way
  around.
- **Bookmarks:** bookmarks added in the browser appear on your devices, and bookmarks
  added on your devices appear in the browser.
- **Highlights and notes:** highlights (five colors) and notes sync in both directions,
  including formatted notes. The browser **Annotations** page lists them all in one place.
- **Browser reader:** create highlights and notes in EPUB and TXT books, and page or
  region notes on PDF and image archives; choose a highlight color from swatches in the
  selection toolbar; add images to notes by https URL; saved library filters and a more
  compact reader toolbar.
- **Private by design:** all of this is stored on your own BiblioFuse server in its
  config folder and is included in BiblioFuse backups. No cloud account is needed.
- Annotation sync is **on by default**. Operators who do not want it can set
  `BF_READER_ANNOTATION_SYNC_V2=false`.

> **Important:** Use BiblioFuse for iOS 2.1.15 or later and
> BiblioFuse for Android 2.0.16 or later on each device.

## Upgrading

Back up the config folder first (Settings can download a BiblioFuse backup). Attached
folders, catalog, reading progress and settings carry over; the annotation database is
created on first start. Docker hosts pull the new tag and recreate the container;
Synology package users update in place.

## One host method per NAS

Do not run the Docker/Container Manager host and native Synology package on the same
NAS. Both intentionally use ports `7342` and `7343`; choose one host method per NAS.
